# Issue tracker

本项目使用 GitHub Issues： https://github.com/yogurt2333/MinaBridge 。

规格父 Issue 为 #1；按 to-tickets 创建独立的纵向任务，正文引用父规格并声明阻塞任务，另设置 GitHub 原生 blocked-by 关系。不要因拆票修改或关闭父规格。

常规拆分、路由与验证决定依据现有规格自主推进；用户已明确覆盖技能中的常规逐步确认要求。产品判断、显著取舍及外部配置不足仍需向用户确认。

本地任务草案与发布映射可以保留在 docs 中；GitHub 为任务状态来源。规格和任务默认使用 ready-for-agent 标签，阻塞关系另行决定是否可开始。
